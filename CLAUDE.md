# CLAUDE.md

Guidance for Claude Code when working in this repository.

## What this is

Roman Season Icons: a Stream Deck icon pack (`uk.novaroma-homelab.season-icons.sdIconPack`, version in its `manifest.json`). It is the companion of the plugin in `stream-deck-season-theme`. The pack is data, not code: PNG files plus an `icons.json` index. Everything is generated by the scripts in `tools/library`.

## Layout

- `uk.novaroma-homelab.season-icons.sdIconPack/`: the pack itself (`manifest.json`, `icons.json`, `icons/`). Never edit `icons.json` or PNGs by hand, regenerate them.
- `tools/library/glyphs.py` and `glyphs_extra.py`: symbol drawings (SVG parts). `glyphs.py` imports `glyphs_extra` at its end.
- `tools/library/render.py`: turns a glyph into the `-off` (outline) and `-on` (filled) PNGs. Keys per glyph: `name, grp, tags, kind ('f' fillable / 'l' line only), body, knock, line, acc, slash, det`. `acc` (rays, glow) is drawn only for On. `det` is drawn in the text colour and again in the background colour, clipped to the body. A Chromium `<clipPath>` may only contain shapes, never `<g>`.
- `tools/library/build_lib.py <pack> [part parts]`, `merge_lib.py <pack>`, `optimize_png.py <pack>`: build, merge into `icons.json`, palette-optimise PNGs.
- `tools/library/redraw.py <pack> <symbol id>...`: re-renders single symbols after a drawing change (all themes, on/off, plain). `thumbnail.py`, `gallery.py` and `previews.py` generate the Marketplace thumbnail, gallery images 2 to 4 and the five season icon previews (also copied into the pack's `previews/`) with the real counts from `icons.json`; rerun them after the icon count changes.
- `docs/NAMING.md`: the naming scheme. `docs/LIBRARY.md`: every symbol by group (generated, do not edit by hand).
- `marketplace/`: thumbnail, gallery, previews, `LIES-MICH.md`.

## Naming scheme (details in docs/NAMING.md)

- File: `<season>-<mode>-<symbol>[-<off|on>][-clear].png`, 144x144 px.
- Seasons: `standard, fruehling, sommer, herbst, winter`. Modes: `light, dark, burgundy`. Toggle badges use `-plus -minus -check -up -down -out`, crossed out is `-slash`.
- Display name: `<Name> [On|Off] (<Season> <Mode>[, no background])`. Tags include Library, Toggle, Off/On, Aus/An, Outline/Filled, the group, and for clear files `No background, Transparent, Ohne Hintergrund`.
- Do not add a symbol under a second name when one exists (for example `desk-lamp`, not `lamp-desk`). Check `docs/LIBRARY.md` first.
- Technical names are English, kebab-case, no spaces, umlauts, dates or versions.

## Working rules

- After adding or changing a glyph: build, merge, optimise, then regenerate `docs/LIBRARY.md`, update the counts in `README.md` and the manifest description, and add a `CHANGELOG.md` entry. Bump the manifest version for a release.
- Keep the pack size in mind. Unoptimised it is about 128 MB, optimised about 54 MB. Always run `optimize_png.py` before packing.
- Check new icons visually (contact sheet via `tools/library/sheet.py`), not only by file count.
- The release file is built with `zip -r Roman-Season-Icons.streamDeckIconPack uk.novaroma-homelab.season-icons.sdIconPack`. Release files do not belong in git.
- The icons are my own drawings. Do not copy Elgato's originals or any third-party artwork.
