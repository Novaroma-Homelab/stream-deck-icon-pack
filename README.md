# Novaroma Season Icons

Stream Deck icon pack with line icons in the Novaroma season colours (standard, spring, summer, autumn, winter) in light, dark and burgundy.

- 3846 icons, 144x144 px: 1923 with tile background and 1923 without background.
- English names and tags, searchable in the Stream Deck icon browser.
- Includes on/off pairs for lights, plugs, doors and more.

## With and without background

Every icon exists twice: the normal tile (`season-mode-name.png`) and a version without any background (`season-mode-name-clear.png`, tag No background). Use the clear ones with a wallpaper or the Stream Deck app background image. Light icons suit dark backgrounds and the other way round.

## Install

Double-click `Novaroma-Season-Icons.streamDeckIconPack` (from the Releases page), or pack the folder yourself:

```
zip -r Novaroma-Season-Icons.streamDeckIconPack uk.novaroma-homelab.season-icons.sdIconPack
```
