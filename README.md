# Novaroma Season Icons

Stream Deck icon pack with line icons in the Novaroma season colours (standard, spring, summer, autumn, winter) in light, dark and burgundy.

- 1923 icons, 144x144 px.
- English names and tags, searchable in the Stream Deck icon browser.
- Includes on/off pairs for lights, plugs, doors and more.

## Clear variant (no background)

`uk.novaroma-homelab.season-icons-clear.sdIconPack` has the same 1923 icons as transparent PNGs: only the symbol is drawn, without the tile, border or background. Use it with a Stream Deck wallpaper or your own key background. Light icons are for dark backgrounds and the other way round. Media for the Marketplace is in `marketplace-clear/`.

```
zip -r Novaroma-Season-Icons-Clear.streamDeckIconPack uk.novaroma-homelab.season-icons-clear.sdIconPack
```

## Install

Double-click `Novaroma-Season-Icons.streamDeckIconPack` (from the Releases page), or pack the folder yourself:

```
zip -r Novaroma-Season-Icons.streamDeckIconPack uk.novaroma-homelab.season-icons.sdIconPack
```
